# Проектная работа Mesto
https://khadzaragov.github.io/mesto-project-ff/

Учебный проект: интерактивная страница с возможностью редактирования профиля и добавления карточек.

Описание
- Используются JavaScript, Fetch API, Webpack.
- Можно редактировать профиль, добавлять/удалять карточки, лайкать, менять аватар.
- Проект адаптивен.
